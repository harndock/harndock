# Harndock Heron Logo

This package is derived from the selected Fibonacci construction study.

## Master assets

- `harndock-heron-mark.svg`: primary mark on transparent background
- `harndock-heron-mark-reversed.svg`: reversed mark for dark backgrounds
- `harndock-heron-mark-mono.svg`: one-color mark
- `harndock-heron-lockup-horizontal.svg`: preferred horizontal lockup
- `harndock-heron-lockup-stacked.svg`: stacked lockup
- `harndock-heron-app-icon.svg`: square application icon
- `harndock-heron-brand-sheet.svg`: visual reference sheet

## Geometry

The mark retains the selected 13, 21, 34, 55, 89 and 144 Fibonacci proportion system. The S-curve identifies the heron, the pointed beak expresses direction, and the horizontal line represents the dock.

## Color

- Indigo 900: `#161D45`
- Indigo 700: `#3F4FB5`
- Indigo 500: `#5267C8`
- Indigo 300: `#9AA7FF`
- Light surface: `#F7F8FC`

Keep clear space around the mark equal to the dock stroke length divided by 13. Use the monochrome mark below 24 px. Do not add outlines, shadows, gradients, or rotate the mark.
