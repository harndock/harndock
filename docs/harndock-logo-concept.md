# Harndock logo concept

第一版概念稿，暂不替换现有 Harndock 生产资源。

## 核心方向

- **图形隐喻**：左右两个码头桩，中间是一段可停靠、可连接的栈桥。
- **品牌含义**：Harndock 代表一个可靠的停靠点，把本地工作台、远程同步和插件能力连接起来。
- **延续性**：保留原 Harndock 标志的竖向支撑、中央连接件和圆角语言，但把中央结构从“加号 / one”转成更明确的“dock / gangway”。

## 颜色

| 用途 | 浅色值 | 深色值 |
| --- | --- | --- |
| 结构 / 码头桩 | `#203A63` | `#9CB7E8` |
| 连接件 / 栈桥 | `#1BA9A1` | `#52C5BC` |
| 连接件内芯 | `#EAF4F2` | `#F4FBFA` |

颜色刻意避开原来的纯 Indigo 主色，让新名字拥有自己的识别点；深色版本只提升明度，不改变图形结构。

## 资源
