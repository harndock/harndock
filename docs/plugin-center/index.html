Plugin Center prototype suite2026 · Product surfaces
Prototype suite / 01

同一套插件系统，
五个清晰入口。

从内容运营后台、线上市场到本地 Runtime，再到组织治理与移动审批。每个端只承担最适合自己的任务，组合成完整的插件生命周期。

⌘01 / DESKTOP

Desktop

用户在本地 Harness 内完成插件发现、购买、授权、权限确认、安装、更新和回滚。

打开 Desktop 原型 →
▤02 / CENTER ADMIN

Center Admin

内容管理员维护插件条目、GitHub Release、Manifest、审核、发布、下架和审计记录。

打开管理端原型 →
◇03 / MARKETPLACE

Marketplace

用户侧公开市场负责插件发现、详情和安装引导；V1 不承担后台审核和内容维护。

打开 Marketplace 原型 →
◎04 / GATEWAY

Gateway

组织管理员管理插件策略、成员席位、私有插件源、安装任务和审计记录。

打开 Gateway 原型 →
⌁05 / MOBILE

Mobile

移动端提供轻量资产查看、远程安装审批、许可证状态和设备管理，不承担支付主流程。

打开 Mobile 原型 →
推荐评审顺序：Center Admin 内容运营 → Marketplace 用户市场 → Desktop 本地安装 → Gateway 组织治理 → Mobile 远程审批。
五个原型均为本地静态 HTML，不连接真实账号、支付、Gateway 或 Harness。
